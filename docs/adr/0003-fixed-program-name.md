# ADR-0003: helpの表示名を`vde-open`に固定する

状態: 採用（P0）

## 背景

`vde-open`と`vo`は同じentryを指す（仕様3章）。CLI-002は、両名の機能とversionが一致することを求める。仕様3章は、呼び出し名からstateやdaemonの識別子を作らないことも求める。

## 決定

helpのUsageに出す名前は、呼び出し名によらず`vde-open`にする。helpの末尾に、`vo`が同じコマンドであることを1行で示す。

## 理由

両名の出力が完全に一致するので、pack検証で文字列比較できる。呼び出し名を読む処理がなくなり、名前に依存した分岐が入り込まない。
